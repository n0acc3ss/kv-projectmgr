## วัตถุประสงค์

1. พัฒนาระบบการเรียนรู้สาธารณะ (e-Learning) สำหรับผู้ประกอบการ MSME ด้วยเทคโนโลยีดิจิทัล
2. พัฒนาและบูรณาการองค์ความรู้ที่เป็นประโยชน์ต่อ MSME ร่วมกับหน่วยงานพันธมิตร
3. เผยแพร่ความรู้ผ่านช่องทางดิจิทัลที่หลากหลาย ลดความเหลื่อมล้ำในการเข้าถึงองค์ความรู้ธุรกิจ

## ขอบเขตงาน (TOR)

### 5.1 — พัฒนาและจัดทำองค์ความรู้
- [ ] จัดทำแนวคิดองค์ความรู้ระดับ Fundamental/Intermediate จำนวน **5 เรื่อง** พร้อมรายชื่อวิทยากร
- [ ] คลิปวิดีโอแต่ละเรื่อง ≥45 นาที | Full HD (1920×1080) | มี Subtitle ภาษาไทย
- [ ] Teaser clip 30 วินาที – 1 นาที ต่อ 1 เรื่อง
- [ ] Pre-Test / Post-Test พร้อมเฉลย
- [ ] จัดประชุมรับฟังความคิดเห็น (Stakeholders) อย่างน้อย **1 ครั้ง**
- [ ] ใบประกาศนียบัตรดาวน์โหลดได้

### 5.2 — พัฒนาและบริหารจัดการระบบ SME Academy 365
- [ ] Cloud Hosting รองรับผู้ใช้งานพร้อมกันจำนวนมาก
- [ ] ระบบ Full Backup | ข้อมูลสถิติผู้ใช้งานหลายมิติ
- [ ] เชื่อมต่อ API กับระบบ สสว. อื่น ๆ (SME Connext / SME ONE ID / SME Profile)
- [ ] Single Sign-On (SSO) จากระบบ SME CONNEXT
- [ ] รองรับผู้ลงทะเบียน (Enrolled) ≥ **1,500 ราย**
- [ ] Cloud costs รับผิดชอบถึง 30 ก.ย. 2570

### 5.3 — จัดกิจกรรมอบรม (Public Training)
- [ ] จัดอบรม Onsite **6 ครั้ง** ทั่วประเทศ (ตามที่ สสว. เห็นชอบ)
- [ ] ผู้เข้าร่วม ≥ **50 ราย/ครั้ง**
- [ ] จัดทำแบบสำรวจความพึงพอใจ (Questionnaire) + สรุปผล

### 5.4 — เชื่อมโยงหน่วยงานพันธมิตร
- [ ] เชื่อมโยงกับหน่วยงานภาครัฐ/เอกชน/สถาบันการศึกษา ≥ **5 หน่วยงาน**
- [ ] แลกเปลี่ยนองค์ความรู้และขยายเครือข่าย

### 5.5 — บริหารโครงการ
- [ ] ทีมงาน ≥ **10 คน** พร้อมผังโครงสร้าง
- [ ] เจ้าหน้าที่ประสานงาน/ตอบคำถาม ≥ **2 คน** ตลอดโครงการ
- [ ] รายงานความก้าวหน้ารายเดือน (Soft File ทาง e-Mail)

### 5.6 — รับประกันระบบ
- [ ] แก้ไขปัญหาระบบภายใน **24 ชั่วโมง** นับจากวันแจ้ง
- [ ] ส่งมอบ Source Code (Open Source License) พร้อม Documentation
- [ ] ข้อมูลทั้งหมดบนระบบ = ทรัพย์สินของ สสว.

## ความเสี่ยงและบทลงโทษที่ต้องติดตาม

### ค่าปรับ (Penalty)
> **0.10% ของวงเงินค่าจ้างตามสัญญา ต่อวัน**  
> นับถัดจากวันที่ครบกำหนดส่งมอบ จนถึงวันส่งงานถูกต้องครบถ้วน

**ตัวอย่างการคำนวณ:**  
หากล่าช้า 10 วัน = 2,950,000 × 0.10% × 10 = **29,500 บาท**

### ความเสี่ยงหลักที่ต้องเฝ้าระวัง
- [ ] ส่งงานงวด 1 ล่าช้า (กำหนดเข้มงวด: 15 วันแรกหลังลงนาม)
- [ ] จำนวนผู้ลงทะเบียนไม่ถึงเป้า (งวด 2: ≥800 ราย, งวด 3: ≥400 ราย เพิ่มเติม, รวม ≥1,500 ราย)
- [ ] ลิขสิทธิ์เนื้อหา วิดีโอ เพลง — ผู้รับจ้างรับผิดชอบแต่เพียงฝ่ายเดียว
- [ ] การเปลี่ยนแปลงบุคลากรในโครงการ — ต้องได้รับความเห็นชอบจาก สสว.
- [ ] ระบบล่ม — ต้องแก้ไขให้ได้ภายใน 24 ชม.
- [ ] PDPA — การจัดการข้อมูลส่วนบุคคลของผู้เรียน
